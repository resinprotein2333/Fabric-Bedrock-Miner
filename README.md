# Fabric-Bedrock-Miner
A Fabric client mod to "mine" bedrock! Unofficial build adapted for Minecraft 1.21.8.

## About this build

This build provides a community-compiled version for Minecraft 1.21.8, which is not offered by the upstream project. It serves as transitional support for players staying on Leaves 1.21.8 (the latest stable branch) who do not want to switch to the experimental branch.

Once Leaves 1.21.11 becomes stable, you can switch back to the official builds.

## Usage

Have the following items ready:
1. Efficiency V diamond (or netherite) pickaxe
2. Haste II beacon
3. Pistons
4. Redstone torches
5. Slime blocks

Open Config menu with default shortcut `LEFT_ALT+B+C` (can be configured)

Toggle Enable/Disable this mod with default shortcut `LEFT_ALT+B+M` (can be configured)

While the mod is enabled, left click bedrock to "mine" it.

If this mod saves you tons of time, please consider leaving a star on the [upstream project](https://github.com/LXYan2333/Fabric-Bedrock-Miner) to support the original author.
