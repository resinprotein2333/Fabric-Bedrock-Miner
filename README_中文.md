# Fabric-Bedrock-Miner
帮你“挖掘”基岩的客户端 Fabric mod！适配 Minecraft 1.21.8 的非官方构建版

# 非官方构建版本简介
该构建版本旨在为官方没有提供的 Minecraft 1.21.8 提供社区编译版本,为因 Leaves 稳定版停留在 1.21.8 而暂无法升级的玩家提供过渡支持.

未来 Leaves 1.21.11 稳定版发布后即可切换至官方版本.

# 使用
准备好如下物品：
1. 效率 Ⅴ 钻石镐（下界合金也行） 
2. 急迫 Ⅱ 信标
3. 一些活塞
4. 一些红石火把
5. 黏液块若干

使用 `左 ALT+B+C` 快捷键打开配置菜单

使用 `左 ALT+B+M` 开启/关闭本 mod

本 mod 开启状态下，左键单击

所有快捷键均可配置

如果本 mod 帮你节省了大量时间,请去 [上游项目](https://github.com/LXYan2333/Fabric-Bedrock-Miner) 点个 Star 支持原作者.
